02 / PROJECTS

项目档案

项目以可展开的研究记录维护。展开后可以查看研究问题、贡献与方法，未来新增内容也不会让主页无限变长。

01
GEN / 2D · 2023 — 2024

基于图像生成式人工智能的可调结构生成

展开项目 +
研究问题

生成同时满足目标机械性能与设计师结构偏好的二维机械结构，并提升生成结果的可控性与保真度。

主要贡献

提出 CVAE–DDPM 混合架构、指导掩码交互、集成学习标注策略及基于 A* 的结构生成方法。

方法

CVAE · DDPM · Ensemble learning · A*

02
SUR / FEA · 2023 — 2024

基于代理模型的应力场预测与结构优化

展开项目 +
研究问题

用图神经网络增强的卷积代理模型替代昂贵的非线性有限元仿真，实现网格级应力与应变场预测。

主要贡献

融合 U-Net、GraphSAGE 与 SE-ResNet，并引入几何变形损失、LoRA 迁移和 RBF 轮廓优化。

方法

GNN · U-Net · GraphSAGE · LoRA · RBF

03
ROB / DIFF · 2022 — 2023

面向软体机器人设计与轨迹优化的可微代理模型

展开项目 +
研究问题

构建可微预测流程，对气压软体机器人的结构与运动轨迹进行联合优化。

主要贡献

开发带再入袖口的气压软体机器人，并用 U-Net 与 MeshGraphNet 代理模型替代重复有限元分析。

方法

MeshGraphNet · U-Net · Differentiable optimization

04
GNN / TRUSS · 2024

基于图神经网络的桁架结构预测与生成

展开项目 +
研究问题

面向桁架非线性形变预测与可调复杂度结构生成的空间感知图学习框架。

主要贡献

提出 SA-GNN 以降低过拟合和数据需求，并使用条件图变分自编码器生成结构。

方法

SA-GNN · CGVAE · Nonlinear mechanics

05
INV / MDN · 2020 — 2021

负泊松比超材料的生成式逆向设计

展开项目 +
研究问题

根据目标刚度、最大应力和相对密度，生成多样化参数结构的逆向设计框架。

主要贡献

将混合密度生成模型与 MLP 代理模型结合，实现设计自动生成并降低计算成本。

方法

MDN · MLP · Inverse design · Abaqus

06
LLM / CAD · 2023 — 2024

大语言模型在工程设计教育中的应用

展开项目 +
研究问题

从概念生成与详细 CAD 建模两个层面研究大语言模型对工程设计教育的影响。

主要贡献

设计渐进式提示方法，提高大语言模型在工程设计任务中的回答可靠性。

方法

LLM · Progressive prompting · CAD · Design education
